# CallGuard

**Бесплатный блокировщик спам-звонков для Android с открытым исходным кодом.** CallGuard распознаёт и блокирует нежелательные звонки по нескольким базам — сообщества и официальным, работает без интернета и хранит данные только на телефоне.

CallGuard — форк [Yet Another Call Blocker](https://gitlab.com/xynngh/YetAnotherCallBlocker) от **xynngh** (последняя версия 0.5.17, 2021), пересобранный под современный Android, с интерфейсом Material 3 и новыми источниками данных, в первую очередь для Германии.

[English version](README.md) · [Релизы](https://github.com/itmanpapa/Call/releases) · [Лицензия AGPL-3.0-only](LICENSE)

## Возможности

- **Блокировка до звонка** через роль Call Screening (Android 10+).
- **Несколько баз, проверка офлайн:** база YACB, [PhoneBlock](https://phoneblock.net) (бесплатный API-ключ), официальный список [Bundesnetzagentur](https://www.bundesnetzagentur.de/massnahmenliste) (скачивается сам), свои списки (CSV, Fritz!Box XML, vCard — из файла или по ссылке с автообновлением).
- **Карточка звонящего** поверх экрана звонка: рейтинг, категория, источник, кнопки «Заблокировать» / «Не спам».
- **Свои отметки** «спам / не спам» — важнее любых баз, по желанию отправляются в PhoneBlock.
- **Правила блокировки:** шаблоны (`+44*`, `0900*`), скрытые, иностранные и платные номера, расписание, «пропустить повторный звонок».
- **Чёрный список** с шаблонами, свайп «заблокировать» в журнале.
- **Предупреждения о спам-SMS** (по желанию).
- **Проверка работы** — показывает, что мешает защите, и как это исправить.
- **Статистика**, **резервная копия и восстановление**.
- **Material 3**, тёмная тема, **27 языков**, выбор языка в приложении.
- **Обновления внутри приложения** из GitHub Releases (только версия с GitHub).

## Установка

Скачайте `callguard-vX.Y.Z.apk` из **[последнего релиза](https://github.com/itmanpapa/Call/releases/latest)** и установите. Нужен Android 8.0 или новее. Дальше CallGuard сам сообщит о новых версиях.

После первого запуска откройте **Настройки → Проверка работы** и исправьте всё, что отмечено красным.

## Приватность

- Входящие номера проверяются **офлайн** по скачанным базам.
- Онлайн-проверка PhoneBlock (по желанию) отправляет только **хэш** номера.
- Нет аналитики, рекламы и слежки.
- Используемые сетевые сервисы: обновления и отзывы базы YACB («Should I Answer»), PhoneBlock (с вашим ключом), сайт Bundesnetzagentur, GitHub (проверка обновлений). Часть этих сервисов не является свободным ПО.
