# Ручная проверка CallGuard на телефоне

Короткий чек-лист после установки каждой новой версии (5–10 минут). Нужен второй телефон или номер, с которого можно позвонить.

## 1. Установка и запуск
- [ ] Новая версия встала поверх старой, настройки и чёрный список на месте.
- [ ] *Настройки → О приложении* показывает новую версию.
- [ ] *Настройки → Проверка работы*: нет пунктов, отмеченных красным.

## 2. Базы данных
- [ ] *Настройки → Базы данных*: у YACB, PhoneBlock и Bundesnetzagentur стоит «Обновлено: дата · N номеров», нет ошибок.
- [ ] Вкладка «Проверка»: номер из списка спама на phoneblock.net показывает плохой рейтинг и источник.

## 3. Звонки
- [ ] Звонок с номера из контактов: проходит, карточки поверх экрана нет.
- [ ] Звонок с неизвестного номера: появляется карточка CallGuard под окном звонилки; «Не спам» и «×» работают.
- [ ] Добавить второй номер в чёрный список (временно выключить «Использовать контакты», если номер в контактах) и позвонить: звонок сбрасывается, в шторке «Звонок заблокирован», в журнале запись.
- [ ] После проверки убрать номер из чёрного списка и вернуть «Использовать контакты».

## 4. Отметки и правила
- [ ] В журнале свайп вправо по номеру → «Не спам», «Отменить» работает.
- [ ] Карточка номера → «Это спам»: статус PhoneBlock меняется на «Ожидает отправки» → «Отправлено».
- [ ] *Настройки → Правила блокировки*: готовое правило «Скрытые номера» включается и выключается.

## 5. Прочее
- [ ] *Статистика* открывается, числа соответствуют заблокированным звонкам.
- [ ] *Резервная копия → Создать копию* сохраняет файл.
- [ ] *О приложении → Проверить обновления* отвечает «последняя версия» (или предлагает новую).
- [ ] Тёмная тема и смена языка (*Настройки → Язык*) выглядят правильно.

Если что-то не так — сделайте скриншот и запишите шаги.
