## Этап 3. Расширение базы

Результат этапа: несколько независимых источников данных за общим интерфейсом, решение о блокировке принимается за 2–3 секунды даже без сети.

Порядок проверки входящего номера:

1. Контакты и локальный белый список — сразу пропустить.
2. Локальный чёрный список с шаблонами — сразу заблокировать.
3. Офлайн-источники (база YACB, список Bundesnetzagentur, импортированные списки) — мгновенный ответ.
4. Кэш онлайн-ответов (Room, срок жизни 7–30 дней).
5. Онлайн-провайдеры параллельно с таймаутом 1,5 с; не успели — решение по офлайн-данным, ответ сохраняется в кэш.
6. Агрегатор сводит результаты в итоговый рейтинг и категорию, в уведомлении показан источник.

### Задачи по архитектуре

- [ ] Перенести существующую базу YACB в провайдер без изменения формата
- [ ] Кэш онлайн-ответов в Room, настройка срока хранения
- [x] Экран «Базы данных» (единственное место для всех источников): карточки YACB, PhoneBlock, Bundesnetzagentur и своих списков со статусом (дата и число номеров, ход обновления или ошибка) и переключателем; по нажатию — подробности источника с «Обновить сейчас» и его настройками; добавление списка — одна кнопка «Добавить список» (файл или ссылка). Старый экран «Управление базой» из расширенных настроек перенесён в карточку YACB
- [x] Списки по ссылке (телефонная книга Fritz!Box XML, vCard, CSV/TXT) с автоопределением формата, ETag/Last-Modified и ежедневным обновлением через WorkManager
- [x] Правила блокировки (Настройки → «Правила блокировки», код в `data/rules/`): номер или префикс (`+44*`, `0900*`, `*` — любые цифры, `#` — одна цифра), скрытые номера, иностранные номера (код страны отличается от страны из настроек или автоопределения), платные номера Германии, повторный звонок; у каждого правила действие «Блокировать» или «Пропускать» и необязательное расписание (например, 22:00–07:00, через полночь). Правила хранятся в `files/rules/rules.txt` (текстовый формат с версией) и кэшируются в памяти, на пути звонка нет чтения с диска

### Правила блокировки: как принимается решение

1. Правила проверяются по порядку, решает первое подходящее включённое правило, у которого сейчас действует расписание. Порядок меняется перетаскиванием.
2. Контакты (при включённой настройке «Использовать контакты») правило «Блокировать» не трогает, если у правила не снята галочка «Кроме контактов». Правила «Пропускать» к контактам применяются, но контакты и так не блокируются.
3. «Блокировать» работает как чёрный список (в том числе в ограниченном режиме до первой разблокировки — по той же настройке). Если номер есть и в чёрном списке, причиной считается чёрный список.
4. «Пропускать» сильнее рейтингов, импортированных списков, онлайн-источников и настройки «Блокировать скрытые номера», но не сильнее чёрного списка. Когда правило сработало, онлайн-источники не опрашиваются.
5. «Повторный звонок»: если неизвестный (не из контактов) номер уже звонил в пределах окна (по умолчанию 3 минуты, от 1 до 60), звонок пропускается. Звонки запоминаются в памяти приложения; вызовы ближе 10 секунд считаются одним и тем же звонком. Сразу после запуска процесса, пока память не охватывает окно, проверяется системный журнал звонков (10 последних записей). Правило стоит в общем порядке: правило «Блокировать» выше него сильнее.
6. Платные номера Германии — `+49900*` (Premium-Rate, преемник 0190), `+49137*` (массовые звонки, «звонки-приманки»), `+49180*` (сервисные номера; единственный пункт, где возможна блокировка настоящей горячей линии) и `+49190*` (диапазон закрыт в 2005 году, такой номер всегда подделан). Не включены 0700 (личные номера), 118xx (справочные) и 012 (инновационные сервисы): с них практически не звонят. Шаблоны международные, поэтому работают и для национального вида номера, и для пользователей из других стран.
7. «Иностранный» означает другой телефонный код страны: номера +1 (США, Канада и др.) или +7 (Россия, Казахстан) между собой не различаются. Если страна не известна, правило не срабатывает. Короткие номера без кода страны считаются внутренними.
8. В уведомлении и журнале звонков показывается «Правило: …». В журнале звонков правила с расписанием оцениваются по текущему времени, правило повторного звонка — не применяется.

### Источники данных

| Источник | Тип | Покрытие | Условия и риски |
| --- | --- | --- | --- |
| База YACB (Should I Answer) | Офлайн, дельта-обновления | Международное | Уже работает; сервис несвободный, может прекратить работу |
| [Список мер Bundesnetzagentur](https://www.bundesnetzagentur.de/massnahmenliste) | Офлайн, периодический импорт | Германия, номера с официальными мерами | Открытые данные; список небольшой, но надёжный |
| [PhoneBlock](https://phoneblock.net) ([исходники](https://github.com/haumacher/phoneblock)) | Офлайн, ежедневная инкрементальная синхронизация; опционально онлайн-проверка по SHA-1 хешу | Германия (сообщество), частично другие страны | Бесплатно, нужен личный API-ключ пользователя; полная загрузка не чаще раза в месяц, обновления не чаще раза в день; использование на свой риск. Реализовано: источник `phoneblock` (офлайн) и `phoneblock_online` (выключен по умолчанию) |
| Tellows | Онлайн-API | Германия, Австрия, Швейцария и др. | Официальный API для партнёров, частично платный; нужен ключ — уточнить условия |
| Импорт CSV / общие списки | Офлайн | Любое | Свои или сообщества списки; нужна проверка формата |
| Списки сообщества на GitHub (dontobi/SpamCalllist, andreaspreuss/fritzbox_blacklists) | Офлайн, загрузка по ссылке | Германия, ~400 номеров каждый | MIT и GPL-2.0; давно не обновляются (2024 и 2020), поэтому готовых предложений в интерфейсе нет — любой список можно добавить вручную по ссылке |
| Truecaller | Онлайн, неофициальный API | Максимальное | Нарушает условия Truecaller, нужен вход по номеру телефона, риск блокировки аккаунта и поломки API, номера уходят на чужой сервер; только как опция, выключена по умолчанию |

По данным Bundesnetzagentur, только в 2024 году ведомство отключило около 6 500 номеров и получило 154 624 жалобы ([пресс-релиз](https://www.bundesnetzagentur.de/SharedDocs/Pressemitteilungen/DE/2025/20250115_RufMiss.html?nn=659670)).
