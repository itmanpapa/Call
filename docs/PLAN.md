## Цель и исходные данные

Сделать собственный форк Yet Another Call Blocker (YACB): собрать его на современном Android SDK, перевести интерфейс на Material 3 и подключить дополнительные источники данных о спам-номерах, в первую очередь для Германии.

| Параметр | Значение |
| --- | --- |
| Последняя версия | 0.5.17, выпущена 18.11.2021 — проект фактически заброшен |
| Лицензия | AGPL-3.0-only — форк разрешён, исходники форка тоже должны быть открыты |
| Исходный код | [GitLab xynngh/YetAnotherCallBlocker](https://gitlab.com/xynngh/YetAnotherCallBlocker) |

| Минимальный Android | 4.0 |

Источник: [страница приложения в F-Droid](https://f-droid.org/packages/dummydomain.yetanothercallblocker/).

## Этап 3. Расширение базы

Результат этапа: несколько независимых источников данных за общим интерфейсом, решение о блокировке принимается за 2–3 секунды даже без сети.

Порядок проверки входящего номера:

1. Контакты и локальный белый список — сразу пропустить.
2. Локальный чёрный список с шаблонами — сразу заблокировать.
3. Офлайн-источники (база YACB, список Bundesnetzagentur, импортированные списки) — мгновенный ответ.
4. Кэш онлайн-ответов (Room, срок жизни 7–30 дней).
5. Онлайн-провайдеры параллельно с таймаутом 1,5 с; не успели — решение по офлайн-данным, ответ сохраняется в кэш.
6. Агрегатор сводит результаты в итоговый рейтинг и категорию, в уведомлении показан источник.

### Задачи по архитектуре

- [ ] Ввести интерфейс `NumberInfoProvider` (номер → рейтинг, категория, имя, источник) и `ProviderAggregator`
- [ ] Перенести существующую базу YACB в провайдер без изменения формата
- [ ] Кэш онлайн-ответов в Room, настройка срока хранения
- [x] Экран «Источники»: включение и порядок провайдеров, статус и дата обновления каждого

### Источники данных

| Источник | Тип | Покрытие | Условия и риски |
| --- | --- | --- | --- |
| База YACB (Should I Answer) | Офлайн, дельта-обновления | Международное | Уже работает; сервис несвободный, может прекратить работу |
| [Список мер Bundesnetzagentur](https://www.bundesnetzagentur.de/massnahmenliste) | Офлайн, периодический импорт | Германия, номера с официальными мерами | Открытые данные; список небольшой, но надёжный |
| Tellows | Онлайн-API | Германия, Австрия, Швейцария и др. | Официальный API для партнёров, частично платный; нужен ключ — уточнить условия |
| Импорт CSV / общие списки | Офлайн | Любое | Свои или сообщества списки; нужна проверка формата |
| Truecaller | Онлайн, неофициальный API | Максимальное | Нарушает условия Truecaller, нужен вход по номеру телефона, риск блокировки аккаунта и поломки API, номера уходят на чужой сервер; только как опция, выключена по умолчанию |

По данным Bundesnetzagentur, только в 2024 году ведомство отключило около 6 500 номеров и получило 154 624 жалобы ([пресс-релиз](https://www.bundesnetzagentur.de/SharedDocs/Pressemitteilungen/DE/2025/20250115_RufMiss.html?nn=659670)).
